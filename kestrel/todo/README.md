# Kestrel task list

Work we've decided to do later, grouped by topic: one file per topic
(`networking.md`, `combat.md`, ...).

Each task is a `##` heading with:

- **Status:** `open`, `in progress` or `done` (move done tasks to the
  topic's `## Done` section with a link to the PR).
- **Why:** the problem, in a sentence or two.
- **What to do:** the proposed change, or the open question.
- **Where:** files and functions involved.
- **Found in:** the PR, handoff or session it came from.

Keep a task small enough for one session or one agent. Bigger work gets a
handoff document instead, and the task links to it.
