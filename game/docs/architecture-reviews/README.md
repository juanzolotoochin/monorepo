# Architecture reviews

Snapshots of the architecture diagram, one per review, named by date
(`YYYY-MM-DD.html`). Each is a standalone page: open it in a browser. A new
review copies the latest file to a new date and updates it, so two reviews
diff cleanly:

```
git diff --no-index game/docs/architecture-reviews/2026-10-23.html game/docs/architecture-reviews/<later>.html
```
