# Migrate Rust from `rules_rust` to `rules_rs` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the repo's `rules_rust` Rust setup with the hermetic `rules_rs` ruleset while keeping all four `examples/rust/` examples building.

**Architecture:** Swap the `MODULE.bazel` Rust stanza (dep, toolchain, crate resolution) from `rules_rust` + `crate.spec` to `rules_rs` + `crate.from_cargo`, backed by a new minimal root `Cargo.toml`/`Cargo.lock`. Re-point the five example BUILD files at `@rules_rs//rs:*` loads. The `khronos_api` build-script patch is reattached as a `crate.annotation`. Everything — including lockfile generation — goes through the Bazel-managed hermetic toolchain; host `cargo`/`rustc` are never invoked.

**Tech Stack:** Bazel 8.5.1 (bzlmod), `rules_rs` 0.0.61, Rust edition 2021.

---

## Reference: exact `rules_rs` symbols (verified against repo `main`)

- Dep: `bazel_dep(name = "rules_rs", version = "0.0.61")`
- Toolchain ext: `use_extension("@rules_rs//rs/toolchains:module_extension.bzl", "toolchains")`, then `toolchains.toolchain(edition = ..., version = ...)`, `use_repo(toolchains, "default_rust_toolchains")`, `register_toolchains("@default_rust_toolchains//:all")`
- Crate ext: `use_extension("@rules_rs//rs:extensions.bzl", "crate")`, `crate.from_cargo(name, cargo_lock, cargo_toml, platform_triples)`, `crate.annotation(crate, patches, patch_args)`, `use_repo(crate, "crates")`
- Loads: `load("@rules_rs//rs:rust_binary.bzl", "rust_binary")`, `load("@rules_rs//rs:rust_library.bzl", "rust_library")`
- rust-analyzer: `bazel run @rules_rs//tools/rust_analyzer:gen_rust_project`

### Task 2: Migrate the `MODULE.bazel` Rust stanza

**Files:**
- Modify: `MODULE.bazel` (the Rust block, currently lines ~226–249)

- [ ] **Step 1: Replace the entire Rust stanza**

Find this exact current block in `MODULE.bazel`:

```starlark
bazel_dep(name = "rules_rust", version = "0.56.0")

rust = use_extension("@rules_rust//rust:extensions.bzl", "rust")
rust.toolchain(edition = "2021")
use_repo(rust, "rust_toolchains")

register_toolchains("@rust_toolchains//:all")

crate = use_extension("@rules_rust//crate_universe:extension.bzl", "crate")
crate.spec(
    package = "ferris-says",
    version = "0.3.1",
)
crate.spec(
    package = "piston_window",
    version = "0.131.0",
)
crate.annotation(
    crate = "khronos_api",
    patch_args = ["-p1"],
    patches = ["//bazel/patches:khronos_api.patch"],
)
crate.from_specs()
use_repo(crate, "crates")
```

Replace it with:

```starlark
bazel_dep(name = "rules_rs", version = "0.0.61")

rust_toolchains = use_extension("@rules_rs//rs/toolchains:module_extension.bzl", "toolchains")
rust_toolchains.toolchain(
    edition = "2021",
    version = "1.92.0",
)
use_repo(rust_toolchains, "default_rust_toolchains")

register_toolchains("@default_rust_toolchains//:all")

crate = use_extension("@rules_rs//rs:extensions.bzl", "crate")
crate.from_cargo(
    name = "crates",
    cargo_lock = "//:Cargo.lock",
    cargo_toml = "//:Cargo.toml",
    platform_triples = [
        "x86_64-unknown-linux-gnu",
        "aarch64-unknown-linux-gnu",
        "aarch64-apple-darwin",
    ],
)
crate.annotation(
    crate = "khronos_api",
    patch_args = ["-p1"],
    patches = ["//bazel/patches:khronos_api.patch"],
)
use_repo(crate, "crates")
```

- [ ] **Step 2: Verify rules_rust is no longer a direct dep**

Run: `grep -n 'rules_rust\|rust_toolchains//:all\|crate.spec\|from_specs' MODULE.bazel`
Expected: no matches (empty output). `rules_rust` remains available transitively via `rules_rs`; it must not be a direct `bazel_dep` or referenced in `register_toolchains`.

- [ ] **Step 3: Verify the new symbols are present**

Run: `grep -n 'rules_rs\|from_cargo\|default_rust_toolchains' MODULE.bazel`
Expected: shows the `bazel_dep`, the toolchain extension/`use_repo`/`register_toolchains`, and the `from_cargo` call.

- [ ] **Step 4: Commit**

```bash
git add MODULE.bazel
gt modify -c -m "build(rust): switch MODULE.bazel from rules_rust to rules_rs
```

### Task 3: Generate `Cargo.lock` with the hermetic toolchain

**Files:**
- Create: `Cargo.lock`

The lock MUST be produced by the Bazel-downloaded cargo, never `/usr/bin/cargo`.
`rules_rs` registers `@default_rust_toolchains`; fetching it materializes a hermetic
cargo under the Bazel cache.

- [ ] **Step 1: Materialize the hermetic toolchain**

Run: `bazel fetch @default_rust_toolchains//... 2>&1 | tail -5`
Expected: completes without error (downloads the Rust toolchain). If `from_cargo`
errors here about a missing `Cargo.lock`, that is expected — continue to Step 2,
which creates it.

- [ ] **Step 2: Locate the hermetic cargo binary**

Run:
```bash
CARGO=$(find "$(bazel info output_base)/external" -type f -name cargo -path '*rust*' 2>/dev/null | grep -E 'bin/cargo$' | head -1)
echo "$CARGO"
```
Expected: a path under the Bazel `output_base/external/...` ending in `bin/cargo`
(NOT `/usr/bin/cargo`). If empty, run `bazel fetch @rules_rs//...` to force the
toolchain download, then re-run.

- [ ] **Step 3: Generate the lockfile with the hermetic cargo**

Run:
```bash
CARGO=$(find "$(bazel info output_base)/external" -type f -name cargo -path '*rust*' 2>/dev/null | grep -E 'bin/cargo$' | head -1)
"$CARGO" generate-lockfile --manifest-path Cargo.toml
```
Expected: creates `Cargo.lock` at repo root, no error.

- [ ] **Step 4: Verify the lock is real and host cargo was not used**

Run: `head -5 Cargo.lock && echo '---' && which -a cargo`
Expected: `Cargo.lock` starts with `# This file is automatically @generated by Cargo` and lists `ferris-says` / `piston_window` further down (`grep -c 'name = "ferris-says"' Cargo.lock` returns `1`). The `$CARGO` path used in Step 3 must be under the Bazel cache, not `/usr/bin/cargo`.

- [ ] **Step 5: Verify `from_cargo` now resolves**

Run: `bazel build @crates//:ferris-says 2>&1 | tail -10`
Expected: builds the external crate target successfully (proves `from_cargo` read the lock).

- [ ] **Step 6: Commit**

```bash
git add Cargo.lock
gt modify -c -m "build(rust): add hermetically generated Cargo.lock

Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>"
```
